# Création d'un website de résolution de puzzle

Ce projet a pour but de construire un site web pour résoudre des puzzles. La thématique choisie est les cartes du monde.
Ce projet est en cours de développement et n'est pas encore abouti en termes de design et de possibilité offerte. Néanmoins, on peut déjà résoudre deux puzzles différents en plusieurs difficultés, ainsi qu'importer ses propres images. Une adaptation des différentes tailles des emplacements est alors faite pour s'adapter aux mieux à l'image importée.

Pour lancer le projet, la commande à utiliser :

```bash
python app.py
```
